# Dokumentasi Script SQL

Praktikum Modul 11 – Perkembangan DBMS dan Lingkup Penerapan Basis Data  
DBMS: **MySQL** (phpMyAdmin) · Database: `praktikum_modul11` · Proyek: **AirKita**

## Urutan menjalankan

| No | File | Isi | Tahap di laporan |
| -- | ---- | --- | ---------------- |
| 1 | `eksplorasi_DBMS_01.sql` | Identifikasi versi, engine, charset, dan dukungan JSON | Tahap 1 |
| 2 | `basisdata_berorientasi_objek_02.sql` | Representasi objek Laporan AirKita dalam JSON dan penerapannya (baca, ubah, tambah atribut) | Tahap 2 |
| 3 | `Data_Awal_03.sql` | Membuat database, tabel `kategori` dan `produk`, lalu mengisi data awal | Tahap 3 |
| 4 | `pengujian_JSON_04.sql` | SELECT, UPDATE, tambah, hapus, dan cari atribut JSON | Tahap 3 |
| 5 | `pemodelan_data_05.sql` | Tabel `produk_objek` dan pemetaan objek ke relasional | Tahap 4 |

## Catatan

- Jalankan berurutan dari 01 sampai 05.
- File 02 tidak membutuhkan database karena hanya memakai variabel MySQL.
- Pencarian `RAM = '16GB'` pada file 04 tidak menemukan baris karena RAM laptop sudah diubah menjadi `32GB`.
- Repository tidak berisi password database maupun data pribadi.
